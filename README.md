# 🛒 Grocery Shop Billing System

A simple **Grocery Shop Billing System** developed using **Java** and **Object-Oriented Programming (OOP)** concepts with a **Graphical User Interface (GUI)**.

This system is designed to help small grocery shops manage billing efficiently, automatically calculate totals, and reduce manual calculation errors.

## 📌 Project Overview

The Grocery Shop Billing System allows users to:

* Add product details
* Enter product price and quantity
* Calculate item totals automatically
* Calculate the overall bill
* Calculate customer balance
* Generate a bill summary through a graphical interface

The project demonstrates core Java OOP concepts and event-driven programming using `ActionListener`.

## 🏗️ Main Classes

### Product

Stores product information such as:

* Product name
* Price
* Quantity

### Bill

Handles:

* Bill generation
* Total calculation
* Customer balance

### Customer

Stores customer information.

### Billing System

Controls the main system operations and GUI.

## 🧠 OOP Concepts

### Encapsulation

Data members are kept private and accessed using getter and setter methods.

### Polymorphism

Methods can be overloaded to perform different billing calculations.

## 🖥️ GUI Components

The application uses Java Swing components including:

* `JFrame` – Main application window
